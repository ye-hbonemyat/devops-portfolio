# Engineering Lab roadmap

Build these as separate public repositories only when each can be documented, validated and maintained. Do not copy employer code or reproduce private architecture.

Recommended order:

1. `terraform-aws-platform` — strongest broad signal for cloud architecture and IaC consulting.
2. `kubernetes-production-reference` — demonstrates production workload judgment.
3. `gitops-argocd-reference` — shows the operating model around Kubernetes delivery.
4. `aws-finops-automation` — connects technical automation to a clear business result.
5. CI/CD security reference — useful follow-on after the core platform examples.

Detailed specifications are in `docs/plans/`.
